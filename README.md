# SewerPipe Inspector Desktop

Local Windows desktop application for sewer/manhole CCTV review, report-level video inspection, defect capture, 대/중/소 grading, and Excel/PDF report generation.

## Run

```bash
python -m sewerpipe_inspector
```

## Project Structure

- `docs/Requirement_Definition.md`: current requirement definition for Project/Business/Report navigation
- `src/sewerpipe_inspector`: application source
- `tests`: unit tests for core services
